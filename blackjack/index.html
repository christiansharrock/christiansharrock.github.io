// OVERVIEW

Blackjack was the very first project — built to learn Java by doing something fun. The game runs entirely in the terminal, recreating the full casino experience with a clean command-line interface. It proved that the best way to learn programming is to build something you actually want to play.

// FEATURES

  • Full standard 52-card deck with proper shuffle logic
  • Player actions: Hit, Stand, Double Down
  • Dealer AI — hits on 16, stands on 17
  • Blackjack detection (Ace + 10-value = instant win)
  • Ace soft/hard value handling (counts as 1 or 11)
  • Chip-based betting system with persistent balance
  • Win / Loss / Push / Bust outcomes
  • Play-again loop without restarting the program

// WHAT I LEARNED

This project was a crash course in object-oriented design — modelling a Card, Deck, Hand, and Game as separate classes that interact cleanly. It also introduced game-loop thinking: managing state, taking user input, branching on outcomes, and looping until the player wants to quit.
