# Christian — Game Developer Portfolio

Personal portfolio site for Christian, an aspiring game developer.

Built as a static site hosted on GitHub Pages.

## Stack

- Plain HTML, CSS, JavaScript — no build step, no dependencies
- Google Fonts (Press Start 2P, Rajdhani, JetBrains Mono)

## Projects

### Blackjack (Java)

A fully playable Blackjack CLI game written in Java. First ever project.
See the [project page](blackjack/) for details and run instructions.

## Deploying

Push to a GitHub repo, then enable **GitHub Pages** from `Settings → Pages → Deploy from branch → main / (root)`.
